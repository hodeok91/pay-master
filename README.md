# 페이의 달인 — Modular v0.1.4

이 ZIP은 **부분 패치가 아닌 전체 프로젝트 기준본**입니다.

## v0.1.4 결제 흐름 수정

- 등록된 카드는 클릭하지 않습니다.
- 등록된 카드 바로 아래에 **지문 인증 / 비밀번호**가 표시됩니다.
- 지문 인증은 **3초 → 1초 길게 누르기**로 변경했습니다.
- 최초 카드 등록용 비밀번호 설정과 실제 결제용 비밀번호 인증을 완전히 분리했습니다.
- 최초 카드 등록 때만 `비밀번호 등록 → 비밀번호 확인 → 서명`을 진행합니다.
- 카드가 이미 등록된 이후 `비밀번호`를 누르면 등록한 6자리 비밀번호를 **한 번만** 입력합니다.
- 비밀번호 인증이 성공하면 바로 결제 대기 화면으로 이동합니다.
- 결제 대기 화면의 `교육용 리더기에 댔어요` 버튼을 제거했습니다.
- 결제 대기 화면은 들어가자마자 자동으로 결제/NFC 대기 상태가 시작됩니다.
- 제한시간은 50초부터 카운트되며 **매초 짧은 햅틱**이 발생합니다.
- 0초가 되면 자동으로 등록된 카드가 있는 Samsung Wallet 화면으로 돌아갑니다.
- 향후 실제 NFC/키오스크 연동 성공 신호용 `window.PayMasterNfcSuccess()` 진입점을 마련했습니다.
- Android 뒤로가기는 WebView 방문기록이 아니라 앱의 화면 스택만 사용합니다.
- Samsung 하위 화면에서는 이전 앱 화면으로 돌아가고, Wallet 루트에서는 페이 선택 홈으로 돌아갑니다.

## 주의

현재 결제 대기 화면은 **실제 금융 NFC 결제 기능이 아니라 교육용 결제 대기 UI/상태**입니다.
실제 키오스크와의 NFC/HCE 통신은 별도 연동 단계에서 연결합니다.
