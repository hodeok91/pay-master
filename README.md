# 페이의 달인 v0.0.2

교육용 모바일 결제 연습 앱의 Android WebView 기반 테스트 버전입니다.

## v0.0.2
- 검은 화면 방지를 위해 WebView 초기화/로딩 경로를 단순화
- `file:///android_asset/www/index.html`을 명시적으로 로드
- WebView 오류를 화면에 표시하도록 보강
- JavaScript/DOM storage 활성화
- 첫 화면: 페이의 달인 → 삼성페이 연습 진입
- GitHub Actions APK 자동 빌드

이 버전은 실제 결제 앱이 아니라 교육용 시뮬레이터입니다.
