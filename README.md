# 페이의 달인 v0.0.1
특수교육 현장에서 모바일 결제 절차를 연습하기 위한 교육용 Android 시뮬레이터의 첫 테스트 버전입니다.

## v0.0.1 범위
- 스플래시
- 페이 선택 홈
- 삼성페이 연습 모듈 진입
- 달인카드 화면
- 요청형 TIP 도움말의 기본 구조

실제 결제, 실제 카드정보, 생체정보를 사용하지 않습니다.

## GitHub Actions APK
저장소 루트에 파일을 업로드하면 `Build APK` workflow가 실행됩니다. Actions의 artifact `pay-master-v0.0.1-apk` 안에 `app-debug.apk`가 생성됩니다.
